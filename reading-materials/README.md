## 원문 PDF 정책

이 저장소에는 제3자 논문 PDF를 커밋하지 않는다. 카탈로그는 각 논문의 arXiv 초록 페이지와 공개 PDF 주소를 외부 링크로 제공한다.

리딩셋 구성 과정에서는 기준일에 공개된 180편, 총 3,664쪽의 PDF를 로컬에서 내려받아 파일 헤더·페이지 수·크기·SHA-256을 확인했다. 이 검증용 원문 파일과 로컬 경로·해시는 배포 대상이 아니다.

베뉴가 원문 메타데이터에서 확인되지 않는 경우에는 추정하지 않고 `arXiv preprint`로 표시한다. 논문의 개정, 정식 출판, 철회 또는 링크 변경은 카탈로그의 후속 갱신 대상이다.
