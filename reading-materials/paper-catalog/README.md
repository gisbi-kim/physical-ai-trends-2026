## 표기 원칙

- **연도**는 비교 가능한 공통 기준인 arXiv 최초 공개 연도다. 베뉴 표기 안의 연도와 다를 수 있다.
- **베뉴 / 상태**는 arXiv의 `journal_ref`, 출판 DOI, 저자의 명시적 accepted/published comment 순으로 확인했다.
- 근거가 확인되지 않으면 추정하지 않고 `arXiv preprint`로 표시했다. 이는 후속 출판이 없다는 단정이 아니다.
- 저자는 arXiv 메타데이터의 전체 저자 목록을 유지했다.
